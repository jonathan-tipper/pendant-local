# Release notes

## 0.5.0 · 22 September 2026

Initial public source release of Pendant Local.

- Local web dashboard, recording library, search, playback and transcript exports.
- Bluetooth status, clock and recording controls with non-deleting dashboard sync.
- Durable raw captures and journals; exact duplicate and verified partial-version handling.
- Local CPU transcription and optional speaker diarisation with explicit model downloads.
- Source build for an Apple Silicon Mac app using the same backend and storage.
- User/developer guides, security policy, contribution templates and CI configuration.

See [validation](docs/VALIDATION.md) for executed checks and known limits, including
unverified packaged-app Bluetooth, encrypted-audio recovery and Windows installation.
No downloaded speech models, recordings or prebuilt app are included.
